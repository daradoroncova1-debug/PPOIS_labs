# PPOIS Labs

## Лабораторная работа №1: Кубик Рубика

Реализован класс `RubiksCube` на C++ с использованием принципов ООП.
- Вращение граней, перемешивание, проверка на собранность.
- Покрытие unit-тестами (Catch2) > 90%.
- Документация Doxygen.
- CI/CD пайплайн настроен.

### Как запустить:
1. `cmake -B build`
2. `cmake --build build`
3. `./build/lab1_app`
